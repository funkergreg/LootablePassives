[h1]Lootable Passives[/h1]

Pull a passive off a Pal and receive a Disposable Implant.

The game has Disposable Implants for a handful of passives. This mod covers [b]all 115[/b] passives in the game, and gives you two ways to get them.

[b]NEW in version 1.3.0:[/b] tested uninstall procedures with an in-game item cleanup, tested dedicated server support, and settings that change while the game runs through [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3803996980]Better Mod Manager[/url]. See the Changelog at the bottom.

[h2]Benefit[/h2]

One of the main criticisms of the game is that late-game breeding to get the Pal you want is too slow. This takes breeding for exact passives out of the equation and speeds up the road to the ultimate Pal!

[h2]At the Pal Surgery Table[/h2]

Three new operations appear in the passive list, each costing 1,000 gold:

[list]
[*][b]Extract Passive[/b] — removes the passive you selected and returns one matching Disposable Implant.
[*][b]Extract All Passives[/b] — removes every passive on the Pal and returns an implant for each; selecting any passive gives the same result.
[*][b]The passive itself[/b] — one entry per passive you hold a Disposable Implant for; it costs the implant and 1,000 gold.
[/list]

[h2]At the Pal Disassembly Conveyor[/h2]

Queue a Pal as usual. Besides the usual loot, you get a Disposable Implant in your inventory for every passive on the Pal — an automatic Extract All, at no gold cost. Implants that do not fit in your inventory drop at your feet like other world drops.

[h2]What it does not change[/h2]

[list]
[*]Extracting a passive that came from a purchased recipe gives you a [b]single-use implant, never a copy of the recipe[/b]. The bounty and arena token economy for recipes stays intact.
[*]Overwriting a passive with another still destroys the original and yields nothing, as in vanilla.
[*]A Pal still cannot be given a passive it already has, as in vanilla.
[*]The Pal Surgery Table's existing operations are untouched apart from price, which now follows the method: implanting from a reusable recipe costs 5,000, and implanting from a Disposable Implant costs 1,000 — including the game's own Disposable Implants, which were free before.
[/list]

[h2]Multiplayer[/h2]

[list]
[*][b]The host must have this mod,[/b] because the host gives out the items.
[*][b]Every player should run the same version as the host.[/b] Steam Workshop keeps subscriptions current, but a game restart may be needed to pick up the newest version.
[*][b]Tested on a Windows dedicated server[/b] as of 1.3.0: Surgery Table extraction and implants, the Pal Disassembly Conveyor, delivery of owed implants on joining, repair of an interrupted operation at server start, and the item removal. Setup: see Installing on a dedicated server, below.
[/list]

Install this mod on every player's game for full functionality. Tested on two machines with the host modded and the client not: gameplay was stable for both, and extraction and disassembly worked for the host. The client could not use the implants, and this mod's items showed as blank entries in shared storage.

A player with the mod who joins a host without it, or a host with Surgery extraction turned off, does not see this mod's Pal Surgery Table operations, and gets a message saying why.

[h2]Installing on a dedicated server[/h2]

[olist]
[*][b]Install the server.[/b] Windows only: in Steam, open Library → Tools → [b]Palworld Dedicated Server[/b] and install it.
[*][b]Get the three mods.[/b] Subscribe to UE4SS Experimental (Palworld), PalSchema and Lootable Passives in Steam, so Steam downloads them to [i]...\steamapps\workshop\content\1623730\[/i].
[*][b]Start the server once,[/b] then stop it. This creates [i]PalServer\Mods\PalModSettings.ini[/i].
[*][b]Edit [i]PalServer\Mods\PalModSettings.ini[/i][/b] with the server stopped, so it reads:
[code]
[PalModSettings]
bGlobalEnableMod=True
WorkshopRootDir=C:\Program Files (x86)\Steam\steamapps\workshop\content\1623730
ActiveModList=UE4SSExperimentalPW
ActiveModList=PalSchema
ActiveModList=LootablePassives
[/code]
Write one ActiveModList line per mod, with these exact names. WorkshopRootDir is the folder where Steam put the subscriptions. Instead, you can copy the three numbered mod folders into [i]PalServer\Mods\Workshop\[/i] and leave WorkshopRootDir empty.
[*][b]Restart the server.[/b] It installs the mods at launch. [i]PalServer\Mods\ManagedMods\[/i] should then hold UE4SSExperimentalPW, PalSchema and LootablePassives, and [i]PalServer\Mods\NativeMods\UE4SS\UE4SS.log[/i] should contain "Loaded 115 extractable passives".
[*][b]Keep bAllowClientMod on[/b] in the server's world settings; it is on by default. Players install Lootable Passives and its two requirements in their own game.
[*][b]After a mod update,[/b] restart the server so it installs the new version.
[/olist]

[h2]Settings[/h2]

With Better Mod Manager installed, the settings appear on its Mods tab and take effect while the game runs. Without it, edit [i]...\Mods\NativeMods\UE4SS\Mods\LootablePassives\Scripts\config.lua[/i] (under the game folder, or the PalServer folder on a dedicated server) with the game or server stopped, then start it. A dedicated server always uses this file. A change made in Better Mod Manager is saved into it too.

[list]
[*][b]Surgery extraction[/b] (surgery_extraction, default on) — Extract One, Extract All and every implant operation this mod adds to the Pal Surgery Table. The host's setting applies to every player. Turned off, the host refuses them and the players' games hide them; the game's own operations are untouched, and nothing already made is taken away.
[*][b]Conveyor extraction[/b] (conveyor_extraction, default on) — Pals fed to the Pal Disassembly Conveyor also yield implants. The host's setting applies.
[*][b]Surgery button check[/b] (surgery_ui_gate, default on) — blocks the Edit button when an operation cannot work. Turn it off if the Pal Surgery Table screen misbehaves.
[*][b]Debug logging[/b] (debug, default off) — extra lines in UE4SS.log for bug reports.
[*][b]Enable advanced features[/b] (advanced_features, default off) and [b]Remove all mod items[/b] (remove_mod_items, default off) — the item removal, required before uninstalling. [b]WARNING: it is destructive.[/b] See Removing this mod's items, below.
[/list]

[b]A mod update replaces config.lua and restores the defaults.[/b] With Better Mod Manager your changes come back on their own; without it, make them again after updating.

[h2]Known Issues[/h2]

[list]
[*]After some operations, the Edit button's coloring in the Pal Surgery Table can be wrong, mostly for clients, and the open screen can keep showing a passive the host has just undone (for example after the host turned Surgery extraction off). Close and reopen the menu to redraw it.
[*]A player with this mod who joins a host without it sees this mod's prices for the game's own implant operations, but the host charges the game's prices: a recipe operation listed at 5,000 gold costs 50,000. This mod's own operations are hidden in that case.
[/list]

[h2]Mod Compatibility[/h2]

This mod changes Disposable Implants, the purchasable passive recipes (arena and bounty), and how the Pal Surgery Table and Pal Disassembly Conveyor behave. Do not use it together with other mods that change the same things — choose one — since two mods acting on the same thing are likely to conflict and crash the game.

[h2]Removing this mod's items from the world (host only)[/h2]

This is the first step of uninstalling; the full steps are under Uninstalling, below. It runs while both [b]Enable advanced features[/b] and [b]Remove all mod items[/b] are on, and takes about 25 seconds in a large world.

[list]
[*]It removes this mod's implants from the inventories and chests loaded in the world, and the ones still owed to players. Every player then sees a message with the number removed, and [b]Remove all mod items[/b] turns itself off. If anything is left, it stays on and runs again the next time the world is entered or a player joins.
[*]The game's own Disposable Implants are left alone, and Pals keep every passive they have.
[*]Implants lying on the ground, and containers not loaded at the time, are not reached; the result is written to UE4SS.log.
[*]On a dedicated server it runs once a player is online. Have every player who holds this mod's implants online while it runs, so their inventories are reached.
[*]Back up your world first.
[/list]

[h2]Uninstalling[/h2]

[b]WARNING: remove this mod's Disposable Implants from the world before you uninstall it.[/b] Once the mod is gone, a player who still carries its implants crashes a dedicated server as they join: the world loads, and the crash comes as that player arrives. With the implants removed first, the same world and player joined the unmodded server normally. Hosting co-op from your game was not tested without the removal, so do it there too. Passives already implanted are real passives and stay on the Pal either way.

Two things worth knowing first, both general to Palworld modding. Pocketpair's guidance is that turning a mod off is not always enough, and that files left in the game folder can still be loaded: if you have ever installed mods by hand, delete those with File Explorer and verify your game files through Steam. And a save loaded with mods can keep showing problems afterwards, so back up a save you care about first.

[h3]Dedicated server[/h3]

[olist]
[*]Stop the server. In [i]PalServer\Mods\NativeMods\UE4SS\Mods\LootablePassives\Scripts\config.lua[/i], set [i]advanced_features = true[/i] and [i]remove_mod_items = true[/i].
[*]Start the server, and have every player who holds this mod's implants join. The removal runs once a player is online; each player sees "the host removed N of this mod's implants from the world", and the server's UE4SS.log has a "Removed this mod's implants from the world" line with the counts.
[*]Keep the server running for a minute after that, so it saves the world without the implants.
[*]Stop the server, take the [i]ActiveModList=LootablePassives[/i] line out of [i]PalServer\Mods\PalModSettings.ini[/i], and start it. The loader removes the mod's files at launch.
[/olist]

[h3]Single player, or hosting co-op from your game[/h3]

[olist]
[*]Enter the world as the host, with every player who holds this mod's implants joined.
[*]On this mod's page in Better Mod Manager, turn on [b]Enable advanced features[/b], then [b]Remove all mod items[/b]. Without Better Mod Manager, quit the game, set [i]advanced_features = true[/i] and [i]remove_mod_items = true[/i] in [i]...\Palworld\Mods\NativeMods\UE4SS\Mods\LootablePassives\Scripts\config.lua[/i], and enter the world again.
[*]Wait for the message "the host removed N of this mod's implants from the world"; the setting then turns itself off. Save, or keep playing a minute so the game autosaves, then quit.
[*]Disable the mod under [b]Options → Mod Management[/b]. Other players can then disable it in their own games.
[/olist]
