[h1]Lootable Passives[/h1]

Pull a passive off a Pal and receive a Disposable Implant. The game has Disposable Implants for a handful of passives; this mod covers [b]all 115[/b], with two ways to get them.

[b]NEW in 1.3.0:[/b] a tested clean uninstall with in-game item removal, tested dedicated server support, and in-game settings through [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3803996980]Better Mod Manager[/url].

[h2]Benefit[/h2]

Late-game breeding for the exact passives you want is slow. This takes it out of the equation and speeds up the road to the ultimate Pal!

[h2]At the Pal Surgery Table[/h2]

Three new operations, each costing 1,000 gold:
[list]
[*][b]Extract Passive[/b] — removes the selected passive and returns its Disposable Implant.
[*][b]Extract All Passives[/b] — removes every passive and returns an implant for each.
[*][b]The passive itself[/b] — implants a passive you hold a Disposable Implant for, using up the implant.
[/list]

[h2]At the Pal Disassembly Conveyor[/h2]

Queue a Pal as usual: besides the usual loot, you get a Disposable Implant for every passive on it, at no gold cost. Implants that do not fit in your inventory drop at your feet.

[h2]What it does not change[/h2]

[list]
[*]Extracting a passive that came from a purchased recipe gives a [b]single-use implant, never the recipe[/b], so the bounty and arena token economy stays intact.
[*]Overwriting a passive still destroys it, and a Pal still cannot get a passive it already has, as in vanilla.
[*]The game's own Surgery operations are untouched apart from price: 5,000 from a recipe, 1,000 from any Disposable Implant, including the game's own (free before).
[/list]

[h2]Requirements[/h2]

[list]
[*]Palworld 1.0, build revision [b]102999[/b] or newer
[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3625223587]UE4SS Experimental (Palworld)[/url]
[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3625280368]PalSchema[/url]
[*]Optional: [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3803996980]Better Mod Manager[/url], for settings in game
[/list]

Subscribe in steam and enable in-game under [b]Options → Mod Management[/b]. See below for multiplayer and dedicated server installs.

[h2]Multiplayer Usage Rules[/h2]

[list]
[*][b]The host must have this mod;[/b] the host gives out the items. 
[*]Every player should run the same version (restart the game after an update).
[*]A player with the mod on a host without it, or with Surgery extraction off, does not see this mod's operations, and gets a message saying why.
[*]A player without the mod cannot use the implants, and sees them as blank entries in shared storage; play is otherwise stable.
[*][b]Tested on a Windows dedicated server[/b] as of 1.3.0: extraction, implants, the conveyor, owed implants delivered on joining, repair of an interrupted operation at server start, and the item removal.
[/list]

[h2]Installing on a dedicated server[/h2]

[olist]
[*]Windows only. Install [b]Palworld Dedicated Server[/b] from Steam (Library → Tools), start it once, then stop it.
[*]Subscribe to the three mods, so Steam downloads them to [i]...\steamapps\workshop\content\1623730\[/i].
[*]With the server stopped, edit [i]PalServer\Mods\PalModSettings.ini[/i] to read:
[code]
[PalModSettings]
bGlobalEnableMod=True
WorkshopRootDir=C:\Program Files (x86)\Steam\steamapps\workshop\content\1623730
ActiveModList=UE4SSExperimentalPW
ActiveModList=PalSchema
ActiveModList=LootablePassives
[/code]
WorkshopRootDir is where Steam put the subscriptions. Or copy the three mod folders into [i]PalServer\Mods\Workshop\[/i] and leave it empty.
[*]Start the server; it installs the mods. [i]PalServer\Mods\NativeMods\UE4SS\UE4SS.log[/i] should contain "Loaded 115 extractable passives".
[*]Keep [b]bAllowClientMod[/b] on (the default). Players install the three mods in their own game.
[*]After a mod update, restart the server.
[/olist]

[h2]Settings[/h2]

With Better Mod Manager, change them on its Mods tab while playing. Otherwise, or on a dedicated server, edit [i]...\Mods\NativeMods\UE4SS\Mods\LootablePassives\Scripts\config.lua[/i] with the game or server stopped. [b]A mod update resets config.lua;[/b] Better Mod Manager restores your changes, otherwise make them again.
[list]
[*][b]Surgery extraction[/b] (surgery_extraction, on) — this mod's Surgery operations. The host's setting applies to all players; off hides them and the host refuses them.
[*][b]Conveyor extraction[/b] (conveyor_extraction, on) — implants from the conveyor. The host's setting applies.
[*][b]Surgery button check[/b] (surgery_ui_gate, on) — blocks Edit when an operation cannot work. Turn off if the Surgery screen misbehaves.
[*][b]Debug logging[/b] (debug, off) — extra UE4SS.log lines for bug reports.
[*][b]Enable advanced features[/b] (advanced_features, off) and [b]Remove all mod items[/b] (remove_mod_items, off) — the item removal; see Uninstalling.
[/list]

[h2]Mod Compatibility[/h2]

This mod changes Disposable Implants, the arena and bounty recipes, the Pal Surgery Table and the Pal Disassembly Conveyor. Do not combine it with other mods that change these; conflicts can crash the game.

[h2]Uninstalling[/h2]

[b]WARNING: remove this mod's Disposable Implants from the world first.[/b] Without the mod, a player still carrying them crashes a dedicated server as they join. With them removed first, the same world and player joined normally. Do it when hosting co-op too. Implanted passives are real passives and stay. Back up your world first.

The removal is [b]destructive[/b], host only, and takes about 25 seconds. It clears this mod's implants from loaded inventories and chests, and any still owed to players; the game's own Disposable Implants stay. Every player sees a message with the count, then [b]Remove all mod items[/b] turns itself off. Anything left keeps it on, to run again at the next world entry or join. Implants on the ground or in unloaded containers are not reached, so have every player holding them online.

[h3]Dedicated Server Uninstall[/h3]
[olist]
[*]Stop the server, and set [i]advanced_features = true[/i] and [i]remove_mod_items = true[/i] in its [i]config.lua[/i].
[*]Start it and have players join. Wait for "the host removed N of this mod's implants from the world", then one more minute so it saves.
[*]Stop it, remove [i]ActiveModList=LootablePassives[/i] from [i]PalModSettings.ini[/i], and start it.
[/olist]

[h3]Single player, or hosting co-op Uninstall[/h3]
[olist]
[*]Enter the world as host, with players holding implants joined.
[*]In Better Mod Manager, turn on [b]Enable advanced features[/b], then [b]Remove all mod items[/b]. (Without it, quit, set both to true in [i]config.lua[/i], and re-enter.)
[*]Wait for "the host removed N of this mod's implants from the world", then save or play a minute, and quit.
[*]Disable the mod under [b]Options → Mod Management[/b]. Other players can then disable it too.
[/olist]

Generally for Palworld mods: turning one off may not remove files you installed by hand (delete them and verify game files in Steam), and a save loaded with mods can keep showing problems, so keep backups.

[h2]Known Issues[/h2]

[list]
[*]The Pal Surgery Table can show a stale Edit button or passive after some operations, mostly for clients. Reopen the menu to redraw it.
[*]On a host without this mod, a client with it sees this mod's prices for the game's own operations, but pays the game's: a recipe listed at 5,000 gold costs 50,000.
[/list]
